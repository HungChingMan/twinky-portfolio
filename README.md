# Twinky Hung portfolio

A dependency-free static landing page. Run `npm run dev` and open http://localhost:5173. Deploy `index.html`, `styles.css`, `script.js`, `assets/`, and `cv/` to any static host.

Content follows `portfolio-master-spec.md`; art direction follows the supplied reference. Original handoff assets remain intact. Selected screenshots are compressed JPEG copies with their original product appearance preserved. Case-study links are omitted because destinations have not been supplied.

Each future narrative interaction has a `data-scene` boundary. Hero forms and About disciplines are separate elements; the Experience path is an SVG; MoodWalk's initial and reframed questions are distinct; PeraFlash conversation and flashcard screenshots are distinct layers. All are readable in their static state. The signature transformations and scroll drawing are deferred.
